# السكة V2

تطبيق ويب تقدمي عربي RTL لمنصة التنقل ومشاركة الطريق.

## التقنيات
- Vite
- Supabase Auth وDatabase
- Cloudflare Pages
- Leaflet وOpenStreetMap

## إعداد المتغيرات
أضف في إعدادات المشروع:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY` (مفتاح Publishable)

لا تضع `service_role` أو أي Secret Key في الواجهة أو GitHub.

## Cloudflare Pages
- Build command: `npm run build`
- Build output directory: `dist`

## قواعد الخدمة والتسعير المعتمدة

### الحجز العادي
- حجز مشوار عادي فوري أو مجدول.
- السعر يحسبه النظام تلقائياً من قواعد `trip_pricing_rules`.
- الحجز للمشوار ككل؛ لا يشترط اختيار عدد كراسي للمشاركة.
- لا يوجد تفاوض على سعر الحجز العادي، سواء كان فورياً أو مجدولاً.

### مشاركة الكراسي وخطوط السير
- التفاوض مرتبط بنوع الخدمة (مشاركة كرسي/خط سير)، وليس بموعدها.
- صاحب العرض، كابتناً كان أو راكباً، يحدد سعر الكرسي عند نشر عرض المشاركة أو المسار.
- الطرف الآخر يرى السعر ويقبله أو يقدم عرضاً مقابلاً.
- نفس القاعدة تنطبق على العروض الفورية والمجدولة.

## تنبيه مهم حول قاعدة البيانات
الملف `supabase/migrations/202611200002_scheduled_trip_negotiation.sql` أصبح **ملغياً وغير صالح للتطبيق**؛ لأنه بُني على ربط التفاوض بالرحلات المجدولة فقط. الملف يحتوي الآن على حاجز يمنع تطبيق التصميم القديم بالخطأ.

لا تشغّل هذا الملف في Supabase SQL Editor. تمت إضافة ترحيل تكميلي `202611200003_unified_share_route_requests.sql` لإنشاء مسار مستقل لطلبات مشاركة خط السير التي ينشرها الراكب أو الكابتن بصفته طالب مقعد. يظل نشر الكابتن للمقاعد والحجز عليها في `rides` و`bookings` دون كسر.
