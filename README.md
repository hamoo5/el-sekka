# السكة

تطبيق ويب تقدمي عربي RTL لمشاركة الطريق والمواصلات الجماعية فقط.

## هوية التطبيق
السكة ليست تطبيق طلب سيارة من نقطة إلى نقطة، ولا تتضمن نظام أوبر أو التاكسي الفردي.

الأنظمة المعتمدة:
1. **جاي في سكتك:** الكابتن ينشر مساره والمقاعد المتاحة، والراكب يحجز مقعدًا على الطريق.
2. **مشوارنا واحد:** مشاركة المقاعد على المسارات المتقاربة وتجميع الركاب على الطريق.
3. **خطوط السكة:** خطوط ثابتة بمحطات ومواعيد ومسارات.

فئات المركبات المسموح بها فقط:
- ملاكي
- سوزوكي
- ميكروباص

## التقنيات
- Vite
- Supabase Auth وDatabase
- Cloudflare Pages
- OpenStreetMap / OSRM لمسارات الطريق

## إعداد المتغيرات
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY` (Publishable key)

لا تضع `service_role` أو أي Secret Key في الواجهة أو GitHub.

## Cloudflare Pages
- Build command: `npm run build`
- Build output directory: `dist`

## ملاحظة تشغيلية
ملفات الترحيلات القديمة تظل محفوظة كسجل تاريخي. لا يعني وجودها أن وظائفها القديمة ما زالت مفعلة. الترحيل الجديد الخاص بإزالة نظام الرحلات الفردية هو المرجع لإيقاف هذه المكونات على قاعدة البيانات.
